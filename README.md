# Hermes34 고객·프로젝트·사이트 데이터 모델

고객 서비스 시트를 정규화하여 운영 가능한 데이터 구조로 전환하기 위한 1차 검수 문서입니다.

- [기존 데이터베이스 필드 매핑 및 이관 규칙](docs/source-field-mapping.md)

## 1차 범위

- 고객 / 연락처
- 프로젝트 / 카테고리
- 사이트 / 도메인 / 호스팅 / 작업자
- 운영 접속 계정의 **비밀값 분리**

실제 DB 생성·데이터 이관·자격증명 이전은 이 문서 검수 후 별도 승인 범위로 진행합니다.
