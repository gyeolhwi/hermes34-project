# 업체·프로젝트·서비스 정합성 점검

## 업체 귀속

- 담당자·프로젝트·서비스의 `company_idx`가 존재하는 `wr_company_t.idx`인지 확인합니다.
- 서비스의 `company_idx`와 부모 프로젝트의 `company_idx`가 같은지 확인합니다.

## 프로젝트·서비스 관계

- 서비스 `parent_idx`가 존재하는 프로젝트 콘텐츠 `idx`인지 확인합니다.
- 프로젝트의 `ref_idx`는 제공된 기준에서 비어 있는 보조 참조값이며 서비스 연결에 사용하지 않습니다.

## 민감정보

- 서비스 `content_raw`는 유효 JSON인지 확인합니다.
- 접속·DB·관리자 계정은 일반 검색 필드가 아니라 서비스 `content_raw.accounts[]`에 보관합니다.
- 민감 계정이 있는 서비스는 `is_hidden=1`인지 확인합니다.

## 코드값

- `status`: `1=운영`, `-1=비운영`
- 서비스 `type`: `1=운영`, `2=개발`, `3=샘플`
- 종료일이 없으면 `date_end=2999-12-31`
